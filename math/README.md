\# 小学四则运算自动生成器



\## 运行环境

\- Python 3.x



\## 功能与使用说明



\### 1. 生成题目

使用 `-n` 参数控制生成题目的个数，使用 `-r` 参数控制题目中数值（自然数、真分数和真分数分母）的最大范围。

\*\*命令示例：\*\*

`python main.py -n 10000 -r 10`

运行后，程序将在当前目录生成 `Exercises.txt` 和 `Answers.txt`。



\### 2. 判题统计

使用 `-e` 参数传入题目文件，使用 `-a` 参数传入答案文件，程序将自动判定对错并统计数量。

\*\*命令示例：\*\*

`python main.py -e Exercises.txt -a Answers.txt`

运行后，程序将在当前目录生成 `Grade.txt`，其中记录了正确与错误的题目数量及编号。
